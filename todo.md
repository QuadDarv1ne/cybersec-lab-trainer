# TODO — Top 10 Improvements for CyberSec Lab Trainer

> Приоритизировано по влиянию: от самого значимого к менее критичному.

---

## 1. Синхронизация заметок и учебных сессий с БД
**Приоритет:** Высокий
Заметки (`notes-system.ts`) и учебные сессии хранятся только в `localStorage`. При смене устройства или очистке кэша все данные теряются.
- Добавить модели `Note` и `StudySession` в `prisma/schema.prisma`
- Расширить API (`/api`) эндпоинтами для сохранения/загрузки заметок и сессий
- Интегрировать с Zustand store (`syncWithDatabase`)

## 2. Лидерборд и социальная геймификация
**Приоритет:** Высокий
XP/уровни и 15+ достижений уже есть, но студенты не могут сравнивать прогресс.
- Глобальная таблица лидеров по XP
- Профили пользователей с витриной достижений
- Делимые карточки достижений (shareable achievement cards)

## 3. Трекер серий (streak) с тепловой картой
**Приоритет:** Высокий
`studySessions` с метками времени уже хранятся, но не визуизируются.
- Виджет на дашборде: текущая серия дней, лучшая серия
- Календарная тепловая карта (как GitHub contributions)
- Драйвер ежедневной вовлечённости

## 4. Квизы по модулям (per-module quizzes)
**Приоритет:** Высокий
Все 80+ вопросов — единый пул, нет привязки к конкретным лабораториям.
- Генерация квиза после завершения каждого модуля
- Отдельный счёт и XP за модульные квизы
- Автоматическая рекомендация: «повтори модуль X, если результат < 70%»

## 5. Интерактивный симулятор атак / Payload Builder
**Приоритет:** Средний
Лаборатории (SQL, XSS, CSRF) проверяют ввод по ключевым словам без визуализации.
- Визуальный XSS payload builder с live-preview (sandboxed iframe)
- SQL injection query builder — видеть изменение запроса в реальном времени
- Пошаговая анимация: «как запрос выполняется на сервере»

## 6. Сертификат по завершении курса
**Приоритет:** Средний
Прогресс и результаты отслеживаются, но нет доказательства для портфолио.
- PDF-сертификат с именем, датой, пройденными модулями, итоговым баллом
- Уникальный ID + QR-код для верификации
- Кнопка «Скачать сертификат» на странице достижений

## 7. Система подсказок с XP-штрафом
**Приоритет:** Средний
SecureCodingLab и челленджи не имеют подсказок — студенты могут застрять.
- Прогрессивные подсказки (общая → конкретная, до 3 уровней)
- Каждая подсказка уменьшает максимальный XP за задачу
- Визуальный индикатор: «подсказка использована, XP −20%»

## 8. Кастомные страницы ошибок и состояния загрузки
**Приоритет:** Средний / Quick Win
Нет `not-found.tsx`, `loading.tsx`, `error.tsx` для App Router.
- 404 с навигацией и поиском
- 500 с описанием и кнопкой «На главную»
- Skeleton-состояния при переключении между модулями

## 9. Оптимизация batch-sync запросов и индексы БД
**Приоритет:** Средний
API использует `Promise.all` с отдельными `upsert` — N+1 при большом объёме.
- Заменить на `prisma.$transaction` с `createMany`/`updateMany`
- Составные индексы: `userId + moduleId`, `userId + quizId`, `userId + challengeType`
- Улучшить debounced sync для слабых соединений

## 10. Доступность: reduced motion и аудит контрастности WCAG AA
**Приоритет:** Низкий / Важно для образовательных учреждений
Framer-motion используется в 20+ компонентах без учёта `prefers-reduced-motion`.
- `useReducedMotion` для отключения анимаций
- Аудит и исправление контраста emerald/slate палитры
- ARIA-метки, keyboard navigation, focus management
